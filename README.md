# Neon Rush

A three-lane cyberpunk endless runner for the browser. Dodge traffic, chain energy orbs, grab a one-hit shield, and switch city themes. Built with React, Three.js, and Vite.

The city scrolls toward you. Change lanes, jump the low barriers, and slide under the high bars. Speed climbs the farther you run. Your best score stays on this device.

## Play

| Action | Keyboard | Touch |
| --- | --- | --- |
| Change lane | A / D or arrow keys | Swipe left or right |
| Jump | W, Up, or Space | Swipe up |
| Slide | S or Down | Swipe down |
| Pause | Esc | — |

Themes: Neon, Toxic, Ember, and Void. The choice is saved with your best score.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173/
